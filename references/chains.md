# 课程例词链选录（畅读导学课 + 阶段二思维导图）

> 来源：《光速单词》畅读导学课例词与《阶段二：4000》思维导图分组。这里保留课堂适用的课程链；“黄健解读”仅作记忆线索。**建链时优先复用现成链。**

## 一、极简案例（词链 1-25）

**morning / evening**
- 1 morning n.早晨；2 evening n.傍晚

**noon → moon → soon**
- 3 noon n.正午；4 moon n.月亮；拓展 5 soon ad.很快
- 解读：noon 与 moon 字母相近，正午与月亮（ noon/moon 同为 o+o 骨架）

**light → night → might → sight**
- 6 light n.光；7 night n.夜晚。**黄健理解：night = no + light**（没有光就是夜晚）
- 拓展 17 might modal v.可能。解读：夜晚无光，很多事物看不清，往往只能看出"可能是什么"
- 拓展 16 sight n.视觉、视野。解读：有光(light)才有视野(sight)；sight = see + light，s 或许借鉴 see 的首字母

**one / none，or / nor，ever / never，either / neither**
- 8 one num.一；9 none pron.没有一个（no+one）
- 10 or conj.否则；11 nor conj.也不
- 12 ever ad.曾经；13 never ad.从不（never = no + ever）
- 14 either pron.任一个；15 neither pron.两者都不

**dad / mom 家族**
- 18 dad；19 mom；20 daddy；21 mommy/mummy；22 father；23 mother；24 pater；25 mater（拉丁）
- 解读：同一家人，字母微调（d/t、m/p 音近）贯穿爸妈称谓

## 三、难词案例（词链 38-47）

- 38 bride n.新娘 ↔ 39 pride n.骄傲。解读：新娘有骄傲（r↔b 音近）
- 40 antique n.古董 ↔ 41 unique a.独一无二的。解读：古董是独一无二的东西
- 42 bruise n.淤青 ↔ 43 blue n.蓝色。解读：淤青是青蓝色（l/r 音近）
- 44 mature a.成熟的 ↔ 45 mater n.妈妈。解读：成熟如母亲（mater 见爸妈家族）
- 46 symbol n.标志 ↔ simple a.简单的：symbol/simple 字母骨架相近
- 47 algorithm n.算法 ↔ logarithm n.对数。解读：仅首部 al/lo 顺序之差

> 健哥点拨：没有什么"难词"，只有"你不懂的词"。懂了的单词不过那么几个字母。

## 四、运用规律·木板家族（词链 174-250 核心）

### 链 A：board → boat → oar → oak → bat → bar（木板、木船、木桨、木棒、木条）

- 174 board n.木板 → 175 boat n.小船。解读：相关连锁，**木板(board)造木船(boat)**（d/t 音近）
- board → 176 oar n.桨。解读：木板还可造木桨。**oar 仿佛从 board 中"对称"取出**——左边去掉 b，右边去掉 d。两个单词传神地讲述了木桨的制作方法
- 177 oar → 178 oak n.橡木。解读：过于相似，或许橡木常被用来做木桨（橡木大而结实）
- board → 179 bat n.木棒。解读：board 中的 b*a*d 与 bat 相似，涉及 d/t
- board → 180 bar n.木条。解读：board 中的 b*ar* 与 bar 相似。bar 相比 bat（r 比 t）读音更软，正好契合意象：bat 是更硬的"木棒"，bar 是较软的"木条（儿）"

### 链 B：bat → battle → combat → beat → defeat → bate → battery → batch → patch → match → watch

- bat → 181 battle n.战斗。解读：**用棒子(bat)战斗(battle)**。汉字"战"中也有"戈"（棒子）；战斗需要不止一个棒子，t 双写表示"多"
- bat → 182 combat n.战斗。解读：**用木棒(bat)战斗(combat)**。combat 相比 battle 更强调现代化战斗
- bat → 183 beat v.拍打、搏动。解读：**用"棒子"(bat)打(beat)**
- beat → 184 defeat n./v.击败、战胜。解读：同向连锁，尾部相通，意思相关。**递进：先打(beat)，然后打败(defeat)**
- beat → 185 bate v.减轻。解读：字母顺序调整。"减轻"意象近似于"打(beat)下去"——"打压…就是让…减轻"
- bat → 186 battery n.电池。解读：**电池(battery)就是一个"棒子"(bat)**。-ery 是表示"集合"概念的后缀
- battery → 187 batch n.一批、一组。解读：**电池(battery)往往成组(batch)使用**，生活中也有"电池组"
- batch → 188 patch n.补丁。解读：**补丁(patch)与被补的事物成"一组"(batch)**
- patch → 189 match n.比赛 v.匹配。解读：**"打补丁"(patch)是"比赛"(match)的行为**（m/p 音近）
- match → 190 watch v.观看。解读：**men 在 match；women 在 watch**

### 链 C：bar → barrier → barrel → band → bandage → bind → bond → bound → boundary → border → abound → abundant

- bar → 191 barrier n.篱笆、栅栏、屏障。解读："篱笆"在汉字中也选了"竹字头"，早期篱笆都用木条竹条制成；**制作篱笆需要不止一个木条(bar)，r 双写表示"多"**
- bar → 192 barrel n.木桶。解读：**木桶由木条(bar)拼合再用铁箍捆上，木条不止一个，r 双写表示"多"**
- bar → 193 band n.布带、布条。解读：字母形象相似 *rn。**bar 是"木条（儿）"，band 是"布条（儿）"**
- band → 194 bandage n.绷带。解读：bandage = band + large。-age 或许取自 large，**绷带是大的"布带"**
- band → 195 bind v.绑定。解读：**用"带子"(band)绑(bind)**（a/i 元音自由）
- bind → 196 bond n.结合物、粘结剂；公债、债券；契约。解读：**结合物、粘合剂(bond)都起到"绑定"(bind)的作用**；"契约""债券"都是将双方绑定(bind)在一起
- bind → 197 bound a.绑缚的；一定的 n.界限。解读：**"界限"(bound)起到"约束作用"，与"绑"(bind)意象相近**
- bound → 198 boundary n.分界线、边界（派生）
- bound → 199 border n.边界、国界 v.接壤。解读：读音相似，意思相近
- bound → 200 abound vi.大量存在；(in/with)充满。解读：**a- 为否定前缀，"不绑了"或"绑不住了"就"大量存在了"**
- 派生：201 abundant a.丰富的；202 abundance n.丰富

### 链 D：board → aboard → abroad → broad（木板→上船→国外→宽阔）

- board → 203 aboard ad.上船/在船上；上飞机。解读：**船和飞机最重要的就是下面的板子，把人托住**。最简易的"船"就是一块板子（竹筏），最简易的"飞机"也是一块板（飞毯）
- aboard → 204 abroad ad.到国外。解读：**"上船、上飞机"(aboard)才能去"国外"(abroad)**
- abroad → 205 broad a.宽的。解读：**"国外"是"宽阔"的地方**，汉语中也有"外面的世界"
- 类似：206 bottle n.瓶子 ↔ bottom n.底部。解读：一个 bottle 最重要的是有 bottom 托住里面的内容
- 类似：208 room n.房间 ↔ roof n.房顶。解读：一个 room 最重要的是有 roof 遮风挡雨

### 链 E：roof → floor → door → window（房屋上下）

- roof → 211 floor n.地板。解读：roof 与 f*oor 是字母顺序调整，一个在上（房屋的顶）一个在下（房屋的底）。**floor 比 roof 多一个 l，loor 整体模仿 low（低），暗示 floor 比 roof 低**
- floor → 214 door n.门。解读：语意相关。floor 地板是块板，door 门也是块板——生活中常说"门板"
- door → 215 window n.窗户。解读：语意相关。**window = wind + door**，door 和 dow 读音相似（讹变或简化），**窗户即是走"风"的门**

### 链 F：low → slow / flow → flood → blood → flu → influenza → influence → influential（水的家族）

- low → slow a.慢的。解读：**慢(slow)就是速度低(low)**
- low → 217 flow v.流。解读：**水往低处(low)流(flow)**
- flow → flood n.洪水。解读：相关连锁，**洪水(flood)在流(flow)**
- flood → blood n.血液。解读：同向连锁。**洪水(flood)在体外流，血液(blood)也在体内流**
- flow → flu n.流感。解读：相关连锁。**"流"存在于具体维度，"流感"存在于抽象维度**
- flu → influenza n.流感（完整形式）→ influence v.影响。解读：相关连锁，字母声音调整 cz*。**流感(influenza)影响(influence)人**
- 派生：influential a.有影响力的（ce 与 ti(al) 声音相似）
- boat → float n.漂浮 v.浮动。解读：**float = flow + boat，船在水流中浮动**
- 派生：fluent a.流利的 / frequent a.频繁的 → fluency n.流利 / frequency n.频繁

### 链 G：flow → blow → glow → gloom → bloom → blossom → flower（吹、光、花的家族）

- flow → blow v.吹 → glow v.发光。解读：相关连锁。生活中常说：**风吹(blow)、日晒(glow)、水洗(flow)，这三种情况都可以把事物的品质或质量降低(low)**
- blow → balloon → ball n.球（气球被吹大）
- blow → blouse n.女士短上衣。解读："女士短上衣"翻译不好，这类服饰的特点在于**"风一吹，衣服的边可以飞"**
- glow → gloom n.阴郁、忧郁。解读：**w 与 m 字母形象相似，翻折对称**——发光的反面是阴郁。派生 gloomy a.阴郁的（加后缀调整词性）
- bloom v.开花 n.花朵 ↔ blossom n.花簇。解读：增减字母，**ss 更体现"花多"**；bloom 是动词"开花"或名词"一朵花"，blossom 是名词"多朵花"
- bloom → boom（繁荣）→ zoom v.猛增猛涨 / doom v.厄运 / loom v.隐隐若现 / boost v.提升。解读：boom 家族连环
- boom → bomb n.炸弹。解读：**炸弹 bomb；爆炸 boom**
- boost → burst v.爆炸；burn v.燃烧 ↔ burst（燃烧/爆炸相伴）
- 类似：blaze v.燃烧 n.火焰 ↔ blast v.爆炸 n.爆炸冲击波
- burn → furnace n.炉子 → fireplace n.壁炉
- flower n.花 ↔ bloom。解读：字母声音调整 bf*（同属 bpmf 辅音音族，汉语拼音也有类似现象）；mw*。bloom 也是"花"，flower 也是"花"

## 五、思维导图补充链（阶段二：4000）

**orange → range → arrange → arrangement → array → rank**
- orange n.橙 → range n.范围、山脉 v.排列 → 293 arrange v.安排、整理（双语论：an zhi 安置）→ 294 arrangement n.安排 → 295 array n.排列、列阵 → rank n.军衔 v.分等级
- 解读：橙子 → 排成行 → 安排 → 排列 → 列阵 → 分等级，"排"意贯穿

**arm → armchair → army；navy / naval**
- 288 arm n.手臂 v.武装 n.武器。解读：**武器是胳臂的延长** → armchair 扶手椅 → army 军队 → navy n.海军 / naval a.军舰的（m/n 音近）

**example → exemplify → sample；exam → examine**
- 1881 example n.例子 → exemplify v.举例证明 → sample n.样品（双语论：试品/样品）→ exam 考试 → examine v.检查（双语论：检验）

**amaze → amazing → gaze**
- amaze vt.使惊奇（双语论：amazed ~ ei ma za de 诶嘛咋的）→ amazing a.惊人的 → gaze v.凝视

**gather → together → altogether → get-together**
- gather 聚集 → together 一起 → altogether 总共 → get-together n.聚会（双语论：tuan ju 团聚）

**area → acre → agriculture → agree → agreement → disagree**
- area 地区 → acre 英亩田地 → agriculture 农业 → agricultural 农业的 → agree 赞同 → agreement 协议 → agreeable 令人愉快的 → disagree 不同意

**anger 家族**
- anger 愤怒 → angry 生气的；anger → danger 危险 → dangerous；anger → rage 暴怒；anguish 极度痛苦 → anxiety 焦虑 → anxious 担心的

**in / into / enter / entry / entrance / entrepreneur；on / onto**
- in 进入 → into 到…里面 → enter 进入 → entry 入口 → entrance 门口 → entrepreneur 企业家（双语论：创办人）
- on 在上 → onto 到…上面

**present 家族 / absent 家族**（见 shuangyu-lun.md 双语论表）
- present → presently 不久 → presence 出席 → presentation 展示
- absent → absence 缺席 → absent-minded 心不在焉的

**boat → board → aboard → embark；charter**
- boat 船 → board 木板 → aboard 上船 → embark v.上船、着手；类似 charter v.租船（broad → broadcast 广播；派生 breadth 宽度——bread- 是变体的 broad，并非面包）

**no / nor / norm / normal 家族**
- no 不 → nor 也不 → norm 准则 → normal 正常的 → normalization 正常化 → abnormal 反常的（a-否定）→ enormous 巨大的（e-出格即"巨大"）

**count → account → accountant → discount**
- count 数 → account 账目、说明 → accountant 会计师 → discount 折扣（双语论：打折扣）
