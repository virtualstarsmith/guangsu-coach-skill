# 双语论（汉英相通）

> 使用边界：双语论是课程提出的记忆绑定方式，不是语言学定论。只有读音骨架、拼音近似和语义都自然吻合时才使用。

> 课程把一部分英语词按汉语拼音近似拼读，绑定到语义吻合的中文短语上。可用时能降低陌生感；不可用时不要硬凑。

## 规则

把英语单词**按汉语拼音的方式近似拼读**，读出来的音若对应一个语义吻合的中文短语，即完成"汉英相通"绑定。例：absent 按拼音近似读作 b-se-t → "不在的"。

**操作要点**：
1. 只取辅音骨架（声母近似），元音可以灵活
2. 必须语义吻合——读音像但意思不搭的不用
3. **牵强的弃用**：宁缺毋滥，双语论解释不了就转连锁法或平实讲解
4. 一个词可有多个对应（entrepreneur 既可读出"创办人"也可读出"主办人"）

## 课程拼音对应例词表

来源：《光速单词（阶段二：4000）》思维导图。格式：`单词 - 声母骨架 ~ 拼音读法 : 中文`

| 单词 | 释义 | 双语论对应 |
|---|---|---|
| absent | a.缺席的；缺乏的 | b se t ~ b zai d → **不在的** |
| absence | n.缺席、不在 | absent 的名词形式 |
| absent-minded | 心不在焉的 | sen b s(a) in de/d ~ xin bu zai yn de → **心不在焉的** |
| present | a.出席的；现在的 | re se t ~ le xi d → **列席的** |
| presentation | n.演示；展示会 | sen tion ~ zhan shi → **展示** |
| entrepreneur | n.企业家；创办人、主办人 | tr p(en) r(eu) ~ ch ban ren → **创办人**；~ zh ban ren → **主办人** |
| discount | n.折扣 v.打折扣 | d s cou ~ d z kou → **打折扣**（折扣） |
| arrange | v.安排、筹划；整理 | arr/an ge ~ an zhi → **安置** |
| examine | v.检查、调查；考试 | xam ine ~ jan yan → **检验** |
| sample | n.样品、标本 | s pl ~ sh pn → **试品**；am pl ~ an pn ~ yang pn → **样品** |
| amazed | 惊奇的 | a ma z d(e) ~ ei ma za de → **诶嘛咋的** |

## 双语论 + 逻辑解读例（课程原注）

- arm（手臂/武器）：**逻辑：武器是胳臂的延长** → armchair 扶手椅、army 军队
- breadth（宽度）：注意 breadth 中的 bread- 并非面包，而是变体的 broad（宽的）

## 与连锁法的配合

一个单词有与之"连锁"的词，还有与之"双语论"对应的汉语。从双语论切入拿下一部分单词，再通过连锁找到相关单词一齐学习——两法联合，"多快好省、稳准狠牢"。

## 使用边界

- 双语论适合**读音与中文短语天然接近**的词（尤其多音节抽象词）；对短词（如 cat、run）通常不如连锁法自然
- 展示给用户时保留"读音近似"的说明（骨架→拼音→中文），让用户自己读一遍加深绑定
- 若用户觉得某个对应牵强，尊重判断，换连锁法——方法服务于记忆，不是教条
