# 连锁法（单词相关）

> 使用边界：这里的“连锁”是课程中的记忆线索，不是词源或语言学结论。对应自然才用；牵强就改为平实讲解。

> 核心论断：英语单词中，有些单词之间存在明显的"拼写或读音"相似，并且单词的意思高度相关（这种"相关"或者是十分明显的，或者是逻辑清晰只不过不加以解读绝大多数人很难发现的）。将单词先"筛选"（找到相互连锁的词划归同组），再"排序"（组内学习顺序优化到最符合人的理解状态），放在一起学习。

让我调整单词中的字母，**能且仅能做这四件事**：

1. 调整字母读音
2. 调整字母形象
3. 调整字母数目
4. 调整字母顺序

（另有**元音相对自由**：元音字母之间的互换不算严格操作，见第 5 节。）

字母串的一维顺序便于比较词形；许多英语词能找到这类线索，但不是所有词都适合这样解释。

## 2. 调整字母形象（形状相似替换）

**(1) 上下翻折相似**
- m/w：wars（战争）↔ Mars（战神/火星）
- n/v：nice（好的）↔ vice（邪恶）；voice（嗓音）↔ noise（噪音）

**(2) 旋转相似**
- c/n：black（黑的）↔ blank（空白的）

**(3) 直观相似**
- n/r：when（什么时候）↔ where（什么地方）；clean（打扫）↔ clear（澄清）；nest（鸟巢）↔ rest（休息）——有巢才有歇处
- v/y：gray（灰色）↔ grave（坟墓）——灰色与坟墓

**(4) 更多了解的形象相似**（书写体）：g/y，r/n/h

## 3. 调整字母数目（增删、双写）

**最明显的例子**（前缀 a-）：
- sleep（睡觉）→ asleep（睡着的）；wake（醒来）→ awake（醒来的）；rouse（唤醒）→ arouse（唤起）

**明显但需要总结的例子**：
- raise（举起）→ praise（表扬）；praise → appraise（评价）

**更多需要总结的例子**：
- bloom（开花/一朵花）→ blossom（花簇）：ss 体现"花多"
- bat（木棒）→ battle（战斗）：战斗需要不止一个棒子，t 双写表示"多"
- bar（木条）→ barrier（篱笆/屏障）：制作篱笆需要不止一个木条，r 双写表示"多"
- bar → barrel（木桶）：木桶由多根木条拼合，r 双写
- band（布条）→ bandage（绷带）：bandage = band + large，-age 或许取自 large，绷带是大的布条
- room（房间）→ broom（扫帚）：brush + room
- battery（电池）= bat + -ery（-ery 是表示"集合"的后缀）

**减少字母数目的例子**：
- clear（清除）→ clarify（澄清、阐明）
- fridge（冰箱）→ refrigerator（冰箱全称）
- region（区域）→ reign（统治）

**双写=多的规律**：tt（battle）、rr（barrier/barrel）、ss（blossom）——字母双写常表示"数量多"。

## 4. 调整字母顺序

- vote（投票）↔ veto（否决）
- lemon（柠檬）↔ melon（瓜）
- top（顶部）↔ bottom（底部）
- roof（房顶）↔ floor（地板）：roof 与 f*oor 是顺序调整，一个在上一个在下；floor 比 roof 多一个 l，loor 整体模仿 low（低），暗示 floor 比 roof 低
- beat（打）↔ bate（减轻）："减轻"意象近似于"打"下去——"打压…就是让…减轻"
- leader（领导）↔ dealer（代理）

## 建链流程

1. **筛选**：在目标词与已掌握词汇中，找出相互"连锁"的词（拼写/读音相似且意义相关），划归同一组
2. **排序**：组内按"由易到难、语义递进"排学习顺序，达到最符合"人"的理解的状态；每一步最好只涉及一次字母操作或一步语义推进
3. **一起学习**：链条 3~8 词为宜；每个环节写一句解读，点破语义逻辑
4. **优先复用**：先查 `chains.md` 里课程现成的词链，避免重复造链
5. **解读风格**：一两句话点破（如"noon→moon、水往低处(low)流(flow)"、"夜晚(night)无光只能看出可能(might)"）；配中文意象类比更佳（如 barrier 对应汉字"篱笆"的竹字头）

## 方法红线（六种被否定的路）

单词不背，英语不会；方法不对，努力白费。
- 死记硬背（含艾宾浩斯式重复）：早晚得跪
- 词根词缀（含格林法则）：一用就废——那是"造词法"不是"背词法"
- 联想谐音（含词源故事）：空口无凭——人人一套没有标准，徒增记忆负担

**建链时严禁**：编谐音故事、字母形象联想故事、用词根词缀硬拆词义。若一个词既做不了双语论、也找不到连锁词，就平实讲解词义+常见搭配，不要编造。
